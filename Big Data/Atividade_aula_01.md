2. Objetivo da atividade

Nesta atividade, sua equipe deverá analisar um problema real e pensar como uma equipe de Ciência de Dados poderia utilizar dados para compreender a situação e apoiar uma decisão.

O objetivo não é desenvolver um sistema ou modelo de Machine Learning neste momento.

O objetivo é aprender a pensar como um cientista de dados:

«Problema → Dados → Informação → Análise → Decisão → Benefício»

13. Os 5 Vs do Big Data

Analise o problema escolhido pela equipe.

V| Pergunta| Resposta da equipe
Volume| Existe uma grande quantidade de dados?| Sim. O histórico acumula centenas de transações diárias, mensais e anuais.
Velocidade| Os dados são gerados ou processados rapidamente?| Sim. Lançamentos e conciliações ocorrem instantaneamente a cada transação.
Variedade| Existem diferentes tipos ou formatos de dados?| Sim. Dados numéricos, carimbos de data/hora, tags de texto e comprovantes.
Veracidade| Os dados podem apresentar erros ou problemas de qualidade?| Sim. Podem surgir inconsistências por erro de digitação ou omissão do usuário.
Valor| Os dados podem gerar algum benefício ou apoiar decisões?| Sim. Convertem registros isolados em inteligência acionável para a vida financeira.

Qual dos 5 Vs é mais relevante para o problema?

«Valor.»

Justifique

«Sem a geração de valor, os dados de movimentação seriam apenas um histórico passivo. A grande relevância está em extrair direcionamentos práticos que alterem de fato o comportamento econômico do usuário.»

Complete o fluxo abaixo:

┌─────────────────────┐
│        PROBLEMA     │

│ de gestão financeira│
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│         DADOS       │
│ Entradas, saídas,   │
│ datas e categorias  │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│     INFORMAÇÕES     │
│ Gargalos de custos e│
│ raio-x orçamentário │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│        ANÁLISE      │
│ Painéis visuais,    │
│ séries e padrões    │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│        DECISÃO      │
│ Teto de gastos e    │
│ readequação de metas│
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│       BENEFÍCIO     │
│ Equilíbrio econômico│
│ e criação de reserva│
└─────────────────────┘

Resuma cada etapa

Problema:

«Ausência de método e clareza no gerenciamento do orçamento e das despesas pessoais.»

Dados:

«Histórico de receitas, contas a pagar, categorias de consumo, datas e vias de pagamento.»

Informação:

«Mapeamento dos principais ralos de dinheiro, comportamento de consumo e saldo líquido real.»

Análise:

«Exploração de séries temporais, gráficos comparativos de entradas versus saídas e identificação de tendências.»

Decisão:

«Eliminação de despesas dispensáveis e estabelecimento de teto de gastos orçamentário.»

Benefício:

«Estabilidade patrimonial, autonomia nas escolhas e segurança financeira.»

17. Reflexão final

Responda individualmente ou em equipe:

«Ter muitos dados significa necessariamente tomar boas decisões? Por quê?»

Resposta:

«Não. O volume isolado de dados não garante eficiência decisória. É indispensável aplicar processos de tratamento, contextualização e análise analítica para converter dados brutos em conhecimento prático. No ecossistema do MVC Finance, os registros só geram impacto real quando traduzidos em estratégias claras para a vida do usuário.»
